# 04 - Site public

## Objectif

Créer un site clair, moderne et dynamique qui donne envie de réserver tout en restant simple.

## Pages

### Accueil `/`

Contenu :

- grande présentation de l'agence ;
- voitures mises en avant ;
- avantages principaux ;
- bouton vers la liste des voitures ;
- bouton vers contact ou réservation ;
- rappel du paiement en espèces.

Animations :

- apparition progressive des sections ;
- transitions légères sur les cartes ;
- effet fluide sur les boutons.

### Liste voitures `/voitures`

Contenu :

- grille des voitures ;
- filtres simples si nécessaire ;
- prix par jour ;
- disponibilité ;
- bouton détail.

### Détail voiture `/voitures/[slug]`

Contenu :

- galerie photos ;
- caractéristiques ;
- description ;
- prix ;
- formulaire ou bouton de réservation ;
- rappel que la réservation doit être confirmée.

### Contact `/contact`

Contenu :

- téléphone ;
- WhatsApp ;
- email ;
- zone de service ;
- horaires ;
- formulaire simple si utile.

## Formulaire de réservation

Champs obligatoires :

- nom complet ;
- email ;
- téléphone ;
- date de début ;
- date de fin.

Champs optionnels :

- message.

Le formulaire doit indiquer clairement :

```text
Le paiement se fait uniquement en espèces au moment de la remise du véhicule.
Votre demande sera confirmée manuellement par téléphone, email ou WhatsApp.
```

## Design

Style recommandé :

- professionnel ;
- moderne ;
- rapide à comprendre ;
- bonnes photos de voitures ;
- interface mobile soignée ;
- animations présentes mais pas excessives.
